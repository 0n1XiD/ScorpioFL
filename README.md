# SCORPIO-АРОМАТЫ | Фронтенд приложение

Веб-приложение е-коммерц платформы для продажи ароматических композиций и пищевых ароматизаторов. Разработано на Vue 3 с использованием TypeScript и Vite.

## 🔧 Требования

Перед установкой проекта убедитесь, что у вас установлены:

- **Node.js** версия 18.0 или выше
- **npm** версия 8.0 или выше (или **yarn**, **pnpm**)

### Проверка установки

```bash
# Проверить версию Node.js
node --version

# Проверить версию npm
npm --version
```

## 📥 Установка

### 1. Распаковка архива

Распакуйте полученный ZIP архив в нужную директорию:

```bash
# Windows
Распакуйте файл через Проводник или используйте PowerShell

# macOS / Linux
unzip SCORPIO.zip
cd SCORPIO
```

### 2. Установка зависимостей

Установите все необходимые пакеты npm:

```bash
npm install
```

Процесс установки включает автоматический запуск `postinstall` скрипта, который применяет патчи к пакетам через `patch-package`.

## 🚀 Запуск

### Режим разработки

Запустите приложение в режиме разработки с горячей перезагрузкой (HMR):

```bash
npm run dev
```

**Вывод:**
```
  VITE v5.0.11  ready in XXX ms

  ➜  Local:   http://localhost:8080/
  ➜  press h to show help
```

Приложение будет доступно по адресу: **http://localhost:8080/**

### Режим производства

#### Сборка проекта

Соберите проект для производства:

```bash
npm run build
```

Процесс сборки включает:
1. Проверку типов TypeScript
2. Оптимизацию и минификацию кода
3. Создание оптимизированной папки `dist/`

#### Предпросмотр собранного проекта

Просмотрите собранную версию перед развертыванием:

```bash
npm run preview
```

### Конфигурация Vite

Основные настройки находятся в `vite.config.ts`:
- Плагины Vue и JSX
- Разрешение алиасов (`@` → `src/`)
- Оптимизация зависимостей

### Конфигурация TypeScript

- `tsconfig.json` - основная конфигурация
- `tsconfig.app.json` - настройки для приложения
- `tsconfig.node.json` - настройки для конфигурационных файлов
- `tsconfig.vitest.json` - настройки для тестов

### Стили

Проект использует **SCSS** с поддержкой:
- Глобальные переменные цветов и размеров
- Переиспользуемые миксины
- Адаптивный дизайн (mobile-first)

**Основные breakpoints:**
- `480px` - большие телефоны
- `600px` - планшеты в портретной ориентации
- `768px` - планшеты в альбомной ориентации

- `1000px` - рабочие столы
- `1200px` - большие рабочие столы

## ❓ Часто задаваемые вопросы

### Q: Какая минимальная версия Node.js требуется?
**A:** Node.js версия 18.0 или выше. Проверьте версию командой `node --version`.

### Q: Как добавить новый маршрут?
**A:** 
1. Создайте новый Vue компонент в папке `src/views/`
2. Добавьте маршрут в `src/router/index.ts`
3. Добавьте название маршрута в `src/router/names.ts`

### Q: Как добавить переводы на новый язык?
**A:**
1. Создайте новую папку в `src/translates/`, например `de/`
2. Создайте файл `main.json` с переводами
3. Добавьте язык в конфигурацию i18n в `src/common/plugins/i18n.ts`

### Q: Как исправить ошибки linting?
**A:** Запустите команду `npm run lint` - она автоматически исправит большинство ошибок стиля.

### Q: Как запустить тесты?
**A:** Используйте команду `npm run test:unit` для запуска всех тестов или `npm run test:unit -- --watch` для режима watch.

### Q: Где найти собранный проект?
**A:** После запуска `npm run build` готовый проект находится в папке `dist/`.

### Q: Как использовать горячую перезагрузку?
**A:** Режим разработки (`npm run dev`) включает HMR автоматически. При сохранении изменений страница обновится без полной перезагрузки.

### Q: Как изменить порт dev-сервера?
**A:** Отредактируйте скрипт `dev` в `package.json` и измените параметр `--port` на нужный портный номер.

### Q: Как добавить новый компонент?
**A:**
1. Создайте файл `.vue` в папке `src/components/`
2. Используйте Composition API с `<script setup>`
3. Импортируйте компонент в нужных местах

### Q: Где хранятся изображения и иконки?
**A:** 
- Иконки: `src/assets/images/icons/`
- Изображения страниц: `src/assets/images/`
